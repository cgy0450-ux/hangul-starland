# 쪼이랜드 v13 — 실제 구현과 검증 기록

원본 쪼이의 얼굴·고글·붉은 스카프를 참조해 내장 ChatGPT 이미지 생성 도구로 제작하고 실제 앱에 적용했다. 외부 유료 이미지/TTS API를 사용하지 않았다. 원본 `joyi-hello.svg`와 관련 원본, `word-gate.js`의 판정·획순·진행 조건은 그대로 보존했다.

## 적용 내용

- 계획한 **221개 삽화**: 게임 장면 11, 과목 장면 10, 동화 장면 200. 모두 실제 WebP 파일이며 홈·놀이터·학습관·동화 화면에 연결했다.
- 별도 지원 자산 **255개**: 사물·동물·공룡·감정·직업·차량·구조 장소 등 투명 그림 242개, 환영/놀이 배경 4개, 색칠 도안 8개와 공방 장면 1개. 일부 지원 그림은 재사용을 위해 보관하며, 모두가 한 화면에 등장한다는 뜻은 아니다.
- 자동차는 위에서 내려다본 전용 그림을 실제 차선·충돌 영역에 맞춰 사용한다. 소방 구조는 12개 장소별 건물, 구조 동물, 소방차, 소화전, 헬리콥터와 불꽃 그림을 사용한다. 물 소비량·무제한 즉시 충전·동물 탭 구조는 유지한다. 단계 사이 글씨쓰기는 사용자 요청으로 켜고 끌 수 있고, 켠 경우 판정·모든 획 완료 조건을 유지한다. 기존 물 게이지 갱신 문제만 수정했다.
- 그림자 게임은 실제 동물 그림의 동일한 실루엣을 사용한다. 색 분류는 실제 빨강/노랑/파랑 물체를 사용한다. 다른 그림 찾기는 동일한 아홉 물체 중 한 위치만 바뀐다. 공룡은 실제 종류와 이름을 맞췄고, 우주 게임은 구별되지 않던 별 다섯 개를 별·달·토성·지구·혜성·로켓으로 구분했다.
- 학습 그림은 정확한 사물·직업·감정으로 연결한다. 여우→고양이, 옥수수→바나나 같은 기존 잘못된 매핑을 사용하지 않는다. 화살표·물음표·금지 표시·달의 위상처럼 기호 자체를 읽는 요소는 정확한 기호로 남긴다.
- 20편 모두 도입·결말을 다듬고 이해 질문을 추가했다. 200개 장면에 인물별 외형 기준을 적용했다. 변신 중 인물 중복과 강아지 귀가 후 결말 오류는 이미지 생성 도구로 재수정했다. 전래동화의 마법·헛소문은 실제 사실과 구분한다.
- 읽어주기에는 부모가 선택한 한국어 음성 우선 사용, 일시정지/이어듣기, 다시읽기, 선택적 자동 넘김, 오래된 재생 종료 이벤트 차단을 추가했다. 실제 기기의 Web Speech 음성이며 생성 음원이라고 주장하지 않는다.
- 실제 휴대폰·태블릿 화면을 보고 제목 끊김, 그림자 넘침, 학습 그림의 잘못된 구석 배치, 점수 위 타이머 겹침을 다시 수정했다.

## 실제 자산과 출처

`asset-plan.json`은 221개 본 삽화와 232개 지원 자산의 경로·치수·해시·출처·검수 상태를 기록한다. `generation/`에는 실제 생성 결과 경로, 등장인물 기준, 장면/사물별 작업 기록, 검수용 연락 시트가 있다. 원본 생성 PNG는 `/workspace/generated_images`에 보존했다. 일부 자산은 정확한 격자의 여러 장면을 한 번에 생성한 뒤 개별 패널로 추출했다. **453개 파일은 453회의 독립 생성 호출을 뜻하지 않는다.** 모든 배포 파일은 서로 다른 내용 해시를 갖는다.

초기 전체 이미지 48,411,230바이트에서 WebP 배포 최적화로 9,067,636바이트를 줄였다. 추가 구조 장소를 포함한 최종 실제 용량과 오프라인 요청 수는 `artifact-results.json`을 참조한다. 원본을 보존했으며 이미 최적화한 WebP를 반복 재압축하지 않는다. 최초 오프라인 설치는 전체 동화까지 내려받으므로 이 용량만큼의 전송이 필요하다. 실제 이동통신망 성능을 측정했다는 뜻은 아니다.

## 검증과 실제 화면

- 기존 `qa/smoke.cjs`, Chrome 브라우저 67개 렌더링 검사.
- Node와 Python의 자산 검사: 실제 파일·해시·중복·검수 메타데이터·오프라인 포함 여부, Python은 이미지 실제 디코딩/치수 확인. 잘못된 자산을 거부하는 부정 테스트 6개.
- `story_review.py`: 200장을 모바일/태블릿에서 각각 표시한 **400개 실제 화면**, 본문/이미지 일치, 20편의 정답·오답 이해 활동. 재수정한 책은 해당 화면을 다시 캡처한다.
- `gameplay.py`: 13개 실제 조작 시나리오. 부분 획과 마지막 획 누락 차단, 전체 획 이후 단계 진행, 실제 소방 구조에서 소방차 세 글자를 모두 쓴 뒤에만 구조 기록 저장, 소화전 연속 충전과 5분 종료 포함. 5분 검사는 원래 프레임 루프에 시간을 공급한 **시뮬레이션**이다.
- `narration.py`: 음성 선택·한국어 설정·일시정지/이어듣기·음소거·자동 넘김·취소 경쟁 조건 검사. 이 검사는 음성 API 대역을 사용하며 실제 스피커 음질 검사가 아니다.
- 오프라인 기본 경로와 쿼리 경로, v12 서비스워커에서 새 버전으로의 실제 교체·이전 캐시 제거 후 탐색.
- `baseline/`은 변경 전, `batch03*`는 단계별 중간 상태다. `story-review/`는 책의 모든 장, `active-review/`는 실제 실행 중 게임/학습/읽기 상태다. `final-screens/`, `size-review/`, `finished-screens/`도 각 실행 시점의 결과 JSON과 실제 화면을 보존한다. 연락 시트는 생성 그림 검수 자료이며 앱 스크린샷과 구별한다.

## 남은 검수와 외부 제한

실제 iPad/Android 터치·기기별 한국어 음성 청취, 모든 440개 학습과 모든 게임의 전체 상태를 하나씩 완주하는 검수는 아직 하지 않았다. 자동 검사·Chrome 화면 확인과 이를 혼동하지 않는다. PR 생성 API는 이전에 `Forbidden`을 반환했다. 그 때문에 개발을 중단하지 않고 기존 개발 브랜치에 커밋·푸시한다. PR 초안은 `PR-DRAFT.md`에 보존한다. 사용자의 반영 요청에 따라 검증을 통과한 앱을 main에 반영한다. 배포 SHA와 Pages 결과는 V13-STATUS.md에 별도로 기록하며, 클라우드 환경 설정 게시와는 구분한다.

## 독자 도안 색칠공방

놀이터의 열두 번째 놀이에서 8개 도안과 영역 채우기·손가락 색칠·지우개·되돌리기·작품방·PNG 저장을 사용할 수 있다. 쓰기 수업은 보존한다. 지정된 외부 캐릭터 도안은 허락 근거가 없어 보류하며, 독자 도안 구현/311개 영역 검사 증거는 `coloring/README.md`에 기록한다.

## 무료 AI 음원

공개 Supertonic 모델을 로컬 CPU에서 실행해 실제 한국어 MP3 693개를 제작했다. 동화 200개 장면과 주요 안내·칭찬·낱말을 포함한다. 유료 API/구독/키가 없고 앱은 정적 음원만 재생한다. 미제작 동적 문장과 영어는 기기 음성으로 보조한다. 실제 미리듣기는 `voice-preview.html`, 조건·재현·검증·청취 한계는 `audio/README.md`에 기록한다.
