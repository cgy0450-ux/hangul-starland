# v13 기준선과 제작 준비

이 디렉터리는 리뉴얼 **착수 증거**다. 상용 품질의 새 삽화나 전체 v13 완성을 의미하지 않는다. 앱 코드, 게임 규칙, 저장 형식, 원본 쪼이 이미지와 서비스워커는 변경하지 않았다.

## 재현

저장소 루트에서 Python 3 + Playwright Python 패키지 + Pillow, Node, 실제 Chrome을 사용한다. 준비된 클라우드에는 설치되어 있다. 서버는 별도 터미널에서 실행한다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

```sh
export PATH="/workspace/joiland-tools/bin:$PATH"
export XDG_CONFIG_HOME=/tmp/joiland-config
export XDG_CACHE_HOME=/tmp/joiland-cache
mkdir -p "$XDG_CONFIG_HOME" "$XDG_CACHE_HOME"
node qa/smoke.cjs
node qa/browser-smoke.cjs
python3 qa/v13/capture.py
python3 qa/v13/behavior.py
python3 qa/v13/assets.py --refresh-inventory
python3 qa/v13/test_assets.py
```

`capture.py --base URL --chrome PATH`로 서버와 Chrome 경로를 바꿀 수 있다. 캡처는 실제 브라우저 렌더링을 WebP로 저장한다. `baseline/results.json`은 경로·크기별 오류와 가로 넘침 관찰값이다. 경고가 없는 캡처도 미적 품질이나 전체 게임 동작을 증명하지 않는다. 무작위 게임 장면은 실행마다 달라질 수 있다. 각 동화의 캡처는 첫 장이며 나머지 장면의 시각 검수는 미완료다.

## 현재 발견한 문제

- `joyi-art-renderer.js`는 여우→고양이, 판다/코알라/소/돼지→곰, 옥수수→바나나, 치즈→레몬, 파인애플→레몬, 브로콜리/오이→나무 등의 의미 불일치를 포함한다. 실제 대상의 새 그림이 준비되기 전 임의 이미지로 교체하지 않는다.
- `stories.html:scenePicture`는 책의 아이콘을 순환 배치한 공통 SVG 배경이다. 본문 사건·공간·인물과 일치하는 200장의 전용 장면은 없다. 첫 장 20편 캡처에서 배경과 배치의 반복을 확인했다.
- 학습 목록은 길고 카드 그림의 비중이 작다. 카드 전용 장면, 제목 위계, 큰 터치 영역을 설계할 필요가 있다. 현재 모바일 캡처는 전체 페이지이므로 작은 연락 시트만으로 글자 가독성을 판정하지 않는다.
- `existing-assets.json`은 현존 이미지의 크기·용량·해시·파일 참조 목록이다. 생성 이력이나 저작권을 소급 인증한 자료가 아니다. SVG 내부 캐릭터/포스터 symbol도 별도로 목록화한다.

## 원본 쪼이 시각 기준

`joyi-hello.svg`와 관련 원본을 정체성 기준으로 보존한다. 둥근 얼굴과 귀, 주황 털·짙은 줄무늬, 흰 입 주변, 눈·코·볼과 머리/몸 비율을 원본 대조로 검수한다. 새 호랑이를 임의로 그려 바꾸지 않는다. 제작 시 원본 렌더링을 실제 참조로 제공해야 한다.

신규 장면은 따뜻한 크림 배경, 청록·보라 계열 조작부와 조화되는 부드러운 입체 동화책 조명으로 통일한다. 사실적인 위협이나 과도한 시각 자극을 피한다. 차량·동물·공룡·음식의 실루엣과 색을 구별하고, 한 이미지에 글자나 조작 버튼을 굽지 않는다. 본문과 읽기 순서는 HTML에 남긴다. 물체와 배경은 게임 히트박스 및 그림자 맞추기를 위해 분리하고 필요한 물체는 투명 WebP/PNG로 만든다.

## 제작 계약과 품질 통과 조건

`asset-plan.json`의 221항목은 게임 카드 11, 학습관 10, 동화 200장의 **초기 제작 목록**이다. 로드맵의 246종 물체/차량/배경 제작량을 대체하거나 충족한 수가 아니다. 모든 항목은 `pending`, `path: null`로 시작한다. 본문을 brief로 옮긴 것만으로 동화 각색·교육적 정확성 검수가 끝나지 않는다.

실제 제작·검수 후에만 `approved`로 전환하고 경로, 크기, 구체적 대체 텍스트, 제작 출처·사용권·실제 생성 방법, 원본 대조 시각 검수 기록을 입력한다. 검증기는 중복 ID, 없는 파일, SVG를 래스터로 둔갑시킨 경로, 중복 래스터, 치수 불일치, 누락된 검수·출처, 오프라인 캐시 누락을 거부한다. `approved` 개수와 검증 통과를 구분한다. 현재 승인된 신규 그림은 **0개**다.

통합 전에는 그림별 의미/색/개체 수/연속성 검수 → WebP 최적화 → 새 manifest 연결 → 실제 모바일/태블릿 캡처 → 게임 동작·획 쓰기·5분 제한·음성·저장 복원 회귀 → 서비스워커 캐시 갱신·기존 버전 업그레이드 검증 순서를 따른다. 기존 자산 참조나 핵심 테스트를 삭제해 검사를 통과시키지 않는다.

## 이미지 생성과 외부 작업의 한계

내장 `image_gen` 도구가 목록에 존재하는 것을 확인했다. 하지만 도구 설명은 호출의 추가 과금 여부를 보장하지 않는다. 사용자 지시가 추가 비용을 금지하므로 **생성 호출·외부 유료 API·유료 업로드를 실행하지 않았다**. 기능의 실생성·원본 참조 편집·결과 다운로드 가능성도 아직 검증하지 않았다. 비용 없는 사용이 확인되거나 사용권이 확인된 전용 원본 삽화가 제공되어야 이미지 제작과 통합을 진행할 수 있다. 이를 그림 생성 완료나 도구 부재로 표현하지 않는다.

Git HTTPS 읽기는 성공했지만 `gh auth status`는 제공된 GitHub API 인증을 유효하지 않은 것으로 보고했다. Git 읽기 성공은 PR API 권한을 보장하지 않는다. 자격증명을 출력하거나 저장하지 않는다.

## 기준선 실행 결과

216개 실제 캡처(54대상×4화면), 관찰된 페이지/HTTP 오류와 가로 넘침은 0이었다. 기본 smoke 및 기존 67개 브라우저 렌더링 검사는 통과했다. 추가 동작 검사에서는 동화 200장과 이전 이동 20편, 51개 캐시 요청을 확인했다. **쿼리 포함 오프라인 학습 경로 검사 실패**는 `baseline/behavior-before.json`에 보존한다. 이 실패를 그림 품질이나 환경 문제로 숨기지 않는다.
