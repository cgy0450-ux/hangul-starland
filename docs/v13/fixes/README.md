# v13.1 사용자 신고 수정 검증

- `final`: 수정한 7개 경로 × 360×800, 390×844, 800×1280, 1280×800 실제 Chrome 캡처. 퀴즈는 시작 화면이 닫힌 뒤의 `quiz` 캡처로 교체했다.
- `verified`: `qa/v13/playability.py`가 실제 문제를 풀며 저장한 화면과 결과. 틀린그림/우주 각각 15문제 × 네 크기, 낱말 27개 전체, 공룡 단계, 설정 유지, 선택 차량의 실제 drawImage 확인.
- `vehicles`: `qa/v13/vehicles.py`의 네 크기 × 두 게임 결과. 실제 조향·수집·회피·충돌을 확인한다. 재현을 위해 Math.random과 RAF 시간을 통제하므로 예시 화면에 같은 물체가 연속할 수 있다. 앱의 무작위 생성 로직을 바꾸지 않는다.
- `quiz`: 시작 화면이 사라진 후의 그림 낱말 퀴즈 네 화면 캡처.
- `initial`: 초기 점검용이며 최종 결과는 위 폴더를 사용한다.
- `new-art-contact.webp`: 내장 이미지 도구로 생성한 신규 14개 그림의 투명 배경 접촉 시트. 앱 캡처와 구분한다.
- `upgrade-from-v13.json`: 직전 서비스의 서비스워커에서 새 버전으로 교체하고, 오프라인에서 새 차량·퀴즈·우주와 설정 유지를 검사한 결과.

Chrome의 실제 렌더링/조작을 viewport 크기로 검사했다. 물리 iPad/Android 터치·스피커 음성 청취는 수행하지 않았다. 배포 후 공개 사이트 직접 접근은 클라우드 네트워크 정책으로 제한되어 GitHub Pages의 성공 SHA를 별도 확인한다.
