# 색칠공방 실제 구현 기록

`generation.json`은 내장 이미지 생성 도구의 원본 출력, 8개 도안별 연결, 311개 영역의 위치와 면적을 기록한다. `game.coloring.webp`는 별도로 생성한 3D 쪼이 공방 장면이다. 모든 원본 PNG를 `/workspace/generated_images`에 보존했다.

`prepare_coloring.py`는 생성된 윤곽선 도안을 추출·패딩하고 채우기용 기술 마스크를 만든다. 기존 삽화 재생성/재압축용 스크립트가 아니다. 마스크는 앱에서 보이는 삽화 개수에 포함하지 않는다.

`verified/results.json`과 실제 화면은 `qa/v13/coloring.py`가 기록한다. 311개 전체 영역을 터치하고, 바깥 픽셀 불변·되돌리기·지우개·실제 모바일 touchStart/move/end·갤러리·복원·PNG 다운로드·키보드·5분 제한을 검사한다. `screens`는 네 viewport의 색칠공방과 놀이터 실제 Chrome 캡처다. 모두 색칠 전·후 화면이며 시안을 완료 화면으로 제시하지 않는다.

마리오/루이지·로보카폴리·타요 이용 허락 근거는 제공되지 않았다. 지정 캐릭터 도안은 보류하고 공개 앱에는 독자 도안만 포함한다. 이름이나 제휴 표시를 차용하지 않는다. 실제 물리 기기와 한국어 음성 청취는 미검증이다.
