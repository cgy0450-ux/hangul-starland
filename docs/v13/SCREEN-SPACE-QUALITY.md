## JOY-005 — 전 학습·놀이 화면 공간 활용 및 그림·뜻 사전학습 품질 개선 (사용자 실기기 피드백, 2026-11-19; 구현 전)
**근거: 사용자 제공 안드로이드 세로 스크린샷 2장.** (A) '생활·감정' 문제 '차에 탔어요. 안전을 위해 무엇을 맬까요?': 수영장/횡단보도/안전벨트 그림 선택지 3개가 큰 카드 상단 일부만 차지, 화면 아래 절반 이상 빈 여백, 안내/음성 버튼이 화면 여기저기 분산. (B) '예술·창의'의 '빨강 / 먼저 그림과 뜻을 알아봐요': 단일 빨간 공 그림이 크게 마련된 패널에 비해 작고, '빨강', '먼저 그림과 뜻을 알아봐요', '쪼이 설명을 들은 뒤 골라봐요', '색깔은 빨강이에요...'처럼 비슷한 텍스트가 수직으로 누적; 음성 듣기와 '이제 골라볼래요!' 버튼은 아래 위치. 앱 기본 틀보다 콘텐츠가 현저히 작음.

### 공통 디자인 요구 (기존 v13 리뉴얼의 보강, 별도 앱/학습 데이터 재작성 금지)
1. **실제 사용 가능 뷰포트에 맞춰 콘텐츠 중심의 유동 레이아웃**. 전체 화면을 단순히 높게 늘리거나 이미지의 비율을 망가뜨리는 것이 아니라, 본문을 시각적 중심으로 재배치하고, 의미 없는 상·하단 공백/중복 패딩/큰 마진을 제거. 과목별 콘텐츠 종류(선택지 그림, 단일 그림, 글씨 캔버스, 게임 터치 타깃 등)에 맞게 비율 지정.
2. **그림을 더 크게**: 실제 중요한 이미지가 카드 너비와 남는 높이를 충분히 활용하도록 이미지 래퍼의 max-width/max-height/object-fit:contain 및 실제 투명 이미지 내부 패딩(여백)을 점검. 카드 컨테이너 확대만으로 내부 그림이 그대로 작아지는 잘못된 수정 금지. 그림의 의미 있는 부분이 선명하게 커져야 함; 잘림·왜곡·정답/힌트 노출은 금지.
3. 화면 상단의 뒤로/홈·소리·문제 진도·트로피 안내는 필요 최소한으로 컴팩트하게 배치. 지시 문장은 **한 번에 한 가지 행동**, 주요 조작(그림 탭, 계속, 다시 듣기 등)은 손이 쉽게 닿는 영역에. '음성 듣기' 여러 개는 목적을 구별해 과도한 중복이 없는지 확인. 5세 글자 읽기 미숙하므로 이미지/자연스러운 자동 안내가 주도하게 할 것.
4. **과목과 게임 전체에 공통 적용**: 생활·감정, 예술·창의만 수정하고 끝내지 말고 기존 10개 영역, 기본 학습/놀이 선택화면, 그림/사물 맞히기, 쓰기, 듣기, 동화, 놀이터 게임 등 실제 route inventory를 기준으로 각각의 화면을 조사. 실제 여백 문제가 있는 화면만 수정해 이미 잘 작동하는 화면을 파괴하거나 중복 제작하지 말 것. 동화 본문 및 그림, 터치 위치 정확성, 쓰기 획 안내·색상 팔레트, 화면 내 모든 컨트롤을 보장.
5. **스크롤 금지와 모든 조작 노출을 동시에 충족**: 화면이 고정인 곳은 스마트폰 status/nav bar와 safe area, 100dvh 적용. 콘텐츠/필수 버튼이 화면 바깥으로 밀리거나 글씨가 겹치지 않도록. 꼭 필요한 긴 콘텐츠는 접근 가능한 별도 레이아웃을 설계하되 overflow:hidden으로 자르지 말 것. 태블릿 가로/모바일 세로 모두 대응. 기존 홈 '하루 3과목' 설계와 충돌 금지.

### '그림과 뜻을 알아봐요' 별도 UX 품질 기준
- 지금 단계는 **큰 그림 제시 → 자연스러운 자동 설명/이름 음성 → 아이가 화면을 보고 이해 → 다음 선택 문제**라는 학습 목적을 유지하되, 그림을 **화면 중심에 크게** 보여 주고 설명을 한 줄 또는 짧은 음성으로 안내.
- 예: 빨간 공은 큼직하게 중앙에 두고 '빨강'을 큰 글자로 한 번 제시. 반복 문장('먼저 그림과 뜻...', '쪼이 설명을 들은 뒤...', '색깔은 빨강...')을 간결하게 통합, 충분한 대비와 재미있는 프레임/쪼이 반응으로 완성도 높이기. 그림 크기와 텍스트의 우선순위를 바꿔야 함.
- '이제 골라볼래요!' 버튼은 한눈에 보이는 위치로 배치. 자동 음성 안내/다시 듣기 유지. **이 단계가 실제로 필요한지 기존 학습 흐름을 분석**하여 불필요한 반복 탭/과도한 사전 단계 강제를 최소화 (바로 문제로 가거나 짧은 도입 후 자연스러운 이동하는 옵션 비교). 학습 목적/단계 순서는 임의 삭제하지 않으며, 보호자 관점에서 변경 이유를 기록.
- 색 분류 등 정답에 영향을 주는 질문은 오답/정답 표시 논리를 유지. 과목별 교육 내용과 그림의 일치, 음성 타이밍 유지. 각 과목의 구체적인 대표 화면을 적어도 하나씩 검수.

### 필수 검증 / 완료 정의
- 모바일 360×640, 390×844, 412×915과 태블릿 가로 1280×800 이상에서 **같은 문제의 전·후 실제 스크린샷** 캡처 및 눈으로 비교. 실기기 별도 확인 항목은 미검증으로 남길 것.
- 그림이 눈에 띄게 확대됐는지 이미지의 실제 렌더링된 bounds/투명 테두리까지 점검. 선택지의 눌림 영역이 큰 채 유지되고 UI 가리는 요소가 없는지 확인.
- 상단/하단 빈 공간, CTA 가시성, 줄바꿈·이미지 잘림, 가로 넘침, 음성·다시 듣기·정답/오답·다음 문제·홈/뒤로 기능 테스트.
- 전체 과목의 화면 목록을 만든 뒤 의미 있는 문제가 발견된 화면에만 조정 적용. 기존 v13 작업과 미완료/완료를 원격 main 및 현재 작업 브랜치에서 대조. 기존 완료 기능은 재작업 금지.
- 작업 단위마다 테스트/실제 브라우저 캡처, 관련 코드 커밋·푸시, V13-STATUS.md 기록. **이 등록은 구현·검증·배포 완료가 아님.**
