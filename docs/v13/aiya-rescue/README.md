# v14.12 — 한글용사 아이야로 영웅 교체

사용자가 새 자동차 구조 동화의 영웅을 한글용사 아이야로 변경하도록 요청했다. 기존 삽화가 있는 원래 스파이더맨 이야기(인덱스21)는 유지하고, 새 구조 낭독판(26번)의 제목·id·franchise·각 장 내용·음원을 바꾼다. ‘배·줄·차’ 글자 카드로 구조를 돕는 새 창작 이야기이며 거미줄/스파이더맨 설정을 남기지 않는다. TV 공식 에피소드/공식 설정 재현으로 주장하지 않는다.

10장 새 본문과 기존 무료 로컬 M4 목소리의 MP3 10개(총231.48초). 모두 끝까지 decode/hash/duration 확인. 이전에 열어 둔 버전의 링크가 깨지지 않게 옛 MP3도 보존한다. 책 인덱스26·전체27편·하루 캐릭터1+일반2·자동 다음 장 설정·이해 활동·다른 게임/진도 유지.

## 그림은 아직 만들지 않았다

아이야의 실제 외형 자료를 확인하려고 공식 EBS 호스트를 조회했으나 이 환경의 proxy CONNECT 403으로 페이지를 읽을 수 없었다. 복장/얼굴을 추측해 다른 캐릭터로 그리거나, 옛 스파이더맨 그림에 이름만 바꾸지 않았다. 이번 영웅의 이미지 생성 자체를 요청하거나 거절받은 상태가 아니다. 정확한 참고 이미지가 필요하다. 계속 명확한 낭독판 표시를 유지한다.

## 검증

- static smoke: 새 id/franchise/제목, 거미줄·스파이더맨 서술 없음, 열 파일/오프라인 캐시, 42일 1+2 순환·KST·이전 과목 순환을 확인.
- audio.json: 실제 CPU 합성 10개 파일을 전체 디코드/해시/길이 확인. 사람의 주관적 청취 승인 아님.
- qa/aiya-probe.html: 실제 공통 stories.html을 iframe에서 로드해 390×844/1280×800의 3편 책장·새 제목/내용·10장 전환·이해 활동·돌아가기·가로 넘침 없음·10개 실제 MP3 native metadata 로드를 검사. 기존 stories 브라우저 case를 더 강한 통합 case로 대체하며 전체72개 필수 유지.
- qa/v13/aiya_story.py: 이전 native playback/auto/pause/replay/offline regression을 새 영웅에 적용한 실행 스크립트. 로컬 Chrome은 pthread_create Resource temporarily unavailable 및 BrowserThread:IO 시작 실패로 실행되지 않아 PASS로 보고하지 않는다. 이전 환경의 누적 프로세스 문제 지속. 실제 72-case browser 검사는 개발 브랜치 GitHub CI에서 main 전에 통과를 확인한다.

외형 미확인·미제작 삽화, 로컬 native 검사 실행 실패, 물리 기기 검수는 완료로 표시하지 않는다. CI 통합 검사와 파일 디코드 결과를 실제 기기 청취/직접 시각 검사로 확대하지 않는다.
