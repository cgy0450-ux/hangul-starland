# v13.5 다섯 학습 화면 실제 개선

- 글자 만나기: 전체 학습지를 가운데 모으던 정렬을 제거했다. 휴대폰은 큰 글자 격자와 예시 카드, 태블릿은 좌우 배치를 사용한다. 읽기 버튼이 카드 밖으로 밀리지 않도록 고쳤다. 세 탭 38개 예시를 모두 실제 그림으로 디코딩·버튼 도달 검사했다.
- 우주 글자 탐험: 전용 가로/세로 3D 우주 배경과 실제 행성 그림 위의 읽기 쉬운 글자 선택지. 좁은 화면에서 풍경이 잘리던 첫 시안을 보고 세로 전용 삽화를 추가했다. 휴대폰·세로 태블릿·가로 화면 모두 확인했다.
- 동물 자동차 여행: 전용 숲길 장면, 기존 쪼이 오픈카 삽화, 실제 동물 그림과 탑승 피드백. 차가 오른쪽으로 진행하도록 방향을 맞추고 남아 있던 평면 도로 줄무늬를 제거했다. 오답 차단과 5문제 완주를 확인했다.
- 영어: CAT 등의 문자 메뉴 대신 고양이 등 뜻에 맞는 그림과 한국어 이름을 누른다. 그림 선택 후 소문자 c→a→t→전체 cat 쓰기. 알파벳 대/소문자 메뉴는 유지한다. PEN은 새 볼펜 그림, ONE/TWO는 실제 사과 한/두 개로 정확히 표현한다. 빈 입력 차단과 모든 글자/전체 단어 완료 저장을 휴대폰·태블릿에서 실제 입력으로 확인했다. 판정 함수를 완화하지 않았다.
- 미로: 칸 중심으로 점프하는 표시 대신 실제 손가락 좌표의 연속 궤적을 그린다. 벽을 통과하지 않는 세밀한 구간 검사, 이미 그린 길에서 재개, 포인터 캡처, 도착 저장, 키보드 이동을 지원한다. 벽/목표와 20개 난이도·저장 키는 유지한다. 그리는 중 벽 DOM을 다시 만들지 않는다. 시작 후 타이머로 판 위치가 밀리거나 가로 화면의 버튼이 잘려 내부 스크롤되던 문제도 수정했다. 5분 종료가 잡고 있는 포인터/키보드 입력을 멈추도록 연결했다.

증거:

- `final`: 5개 경로 × 4개 크기(360×800, 390×844, 800×1280, 1280×800)의 실제 Chrome 화면. 우주는 별도 `space-reviewed`의 최종 세로/가로 캡처로 교체했다. 초기 루트 캡처보다 final을 우선한다.
- `behavior/results.json`: 네 크기에서 20개 미로씩 총 80개를 한 번의 누르기/연속 이동으로 완주. 실제 칸 내부 좌표 일치, 내부/외부 벽과 건너뛰기 차단, 완료 저장. 글자 배치와 영어 그림 선택도 확인.
- `touch-results.json`: 실제 Chrome native touchStart/move/end로 끊김 없이 그리기와 손을 떼고 재개.
- `maze-freehand-mobile.webp`: 곡선의 실제 비중심 좌표를 따라간 화면. 타이머와 상단 버튼이 겹치지 않는 것도 검사했다.
- `letter-art-results.json`: 38개 전체 글자 예시의 실제 그림·가림 없는 읽기 버튼 확인.
- `english-writing-results.json`: 고양이 그림→c/a/t→전체 cat 실제 그리기·완료 저장; 빈 입력 거부.
- `classic-games-results.json`: 두 크기에서 우주/동물 각각 5문제 완주, 오답 차단, 기존 기기 TTS 호출 0회.
- `generation.json`: 실제 생성된 13개 이미지와 원본·투명 배경 보정 출처. 원본 PNG는 `/workspace/generated_images`에 보존. 기존 쪼이 원본은 변경하지 않았다. 단순 SVG·이모지를 새 작화로 대체하지 않았다.

공개 모델을 기존 로컬 CPU에서 실행해 학습 안내 음원도 보완했다(총 825개). 유료 API를 사용하지 않았다. 실제 기기와 사람 청취 평가는 미실시이며 Chrome 화면/터치 에뮬레이션과 혼동하지 않는다. 음원과 전체 오프라인 회귀 증거는 `../audio/offline.json` 등에 있다.
