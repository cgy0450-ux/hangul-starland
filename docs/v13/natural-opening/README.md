# v14.8.1 — 자연스러운 안내와 재생 복구

- 모든 과목을 ‘숲으로’ 부르던 제목을 과학 탐험·역사 시간 여행·독서 이야기 등 실제 주제에 맞게 변경.
- Skip 직후 replay 도중 이전 이미지 decode 완료가 새 연출을 변경하는 경쟁 상태 차단. 재시도 시 숨겨진 이미지 복원, 로딩 실패 안내를 준비 완료와 구별.
- 보호자 설정의 실명 용도는 ‘학습 기록에 쓸 이름’, 별명은 화면 인사 용도임을 구별. 영어 미리듣기 지원/재생 오류 피드백 추가.
- 긴 제목의 폰 세로 화면에서 안내문/skip 겹침 발견 후 제목·소품·마스코트 크기 조정. 작은 가로 기존 보정 유지. 태블릿의 안내 문단 영역도 skip 옆 공간을 예약하여 겹침 방지.

검증: qa/v13/natural_opening.py의 40개 과목/화면 조합, 오래된 decode 무시·실패 후 재시도·음성 오류 안내. 최종 결과 validation.json 참조. 초기 음성 오류 mock은 함수 반환값을 Playwright가 호출하여 실패했으며 실제 이벤트 핸들러 실행 방식으로 수정했다. 검사 기준 완화 없음. 기존 240개 문제의 그림 연결·138개 고유 장면 등록 검사 PASS. 이는 의미 전체의 사람 재검수나 실기기 청취 승인과 다르다.
