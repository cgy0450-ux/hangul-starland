# v13.1: 그림 퀴즈·틀린그림·공룡·우주 진행 수정과 자동차 선택

그림 낱말 퀴즈의 빠진 렌더링 경로와 7개 낱말 매핑을 보완합니다. 내장 이미지 생성으로 오리·하마·기차·가방·비행기·로봇 그림 6개를 추가했고, 실제 출제되는 27개 단어 모두 대응하는 그림으로 표시합니다.

틀린그림찾기와 숨은그림의 절대 위치를 그림 공통 스타일이 덮어쓰면서 물체가 잘리고 정답을 누를 수 없던 문제를 수정합니다. 좌우 9개 중 정확히 한 칸만 다르게 구성하며, 숨은 물체도 크게 배치합니다. 공룡은 알을 먼저 깨고 나온 공룡과 같은 그림을 고르는 순서로 바꿨습니다. 우주 문제는 지시한 별·달·토성·지구·혜성·로켓을 실제 장면과 맞춥니다.

놀이터·각 게임·보호자 화면에 ‘단계 사이 글씨쓰기 연습’ 설정을 추가합니다. 기본은 켜짐이며, 끈 경우 바로 진행합니다. 켠 경우 기존 모든 획 완료 판정을 그대로 사용하고 독립 글씨쓰기 수업에는 영향을 주지 않습니다. 사용자 요청에 따라 AGENTS.md의 단계 쓰기 요구도 이 범위로 수정했습니다.

경찰차·소방차·앰뷸런스·오픈카의 선택 삽화 4개와 대응하는 위에서 본 게임 그림 4개를 새로 제작했습니다. 실제 운전 그림은 선택한 차량과 연결되며 두 자동차 게임에서 크기와 수집·충돌 영역을 함께 조정했습니다. 기존 점수·진행 데이터는 보존합니다.

검증 증거:

- Node smoke, Chrome 67개 렌더링 검사, 실제 467개 WebP 파일·출처·해시·디코딩·오프라인 포함 검사, 오류 거부 사례 6개
- 실제 문제 조작 16개 시나리오: 낱말 27개 전체, 네 화면 크기의 틀린그림 15문제 완주·모든 정답 실제 위치/클릭 검사, 우주 15문제 완주, 부화 전후·오답 차단, 글씨쓰기 설정 유지, 두 게임 네 차량의 실제 Canvas 그림 확인
- 기존 13개 행동 검사: 부분·마지막 획 누락 차단, 모든 획 완료만 통과, 유한 물·반복 충전·5분 제한·소방차 전체 단어 뒤 구조 저장
- 자동차 8개 화면/게임 조합에서 실제 조향·수집·충돌·기존 저장값 보존 확인. 차량 시작 버튼이 스크롤 없이 보이는지도 확인
- 수정한 7개 경로 × 4개 화면 크기 캡처. 그림 퀴즈는 시작 화면이 사라진 후 별도 캡처로 교체
- 오프라인 529개 요청과 구버전 캐시 교체. v13 캐시에서 새 차량·퀴즈·우주 그림과 설정 유지까지 확인
