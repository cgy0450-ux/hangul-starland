# v13.4: 무료 로컬 AI 음원 693개, 동화 200개 장면 실제 재생

기기마다 다른 기본 TTS 대신, 공개 Supertonic 모델을 기존 작업 환경의 CPU에서 실행해 한국어 MP3 693개를 제작했습니다. 동화 20편의 200개 장면과 주요 안내·칭찬·낱말·쓰기 문장을 포함합니다. 유료 API/체험 크레딧/키/신규 구독이 없으며 앱에는 생성된 약 20.7 MB 음원만 배포합니다. 출처·상위 모델 OpenRAIL-M/코드 MIT 안내·동봉 고지를 보존하고 모델 가중치는 공개하지 않습니다.

공통 어댑터가 제작된 문장은 실제 음원으로, 미제작 동적/개인화 문장과 영어는 기존 기기 음성으로 읽습니다. 보호자 화면에 새 AI 음원 토글·미리듣기, 직접 들을 수 있는 샘플 페이지를 제공합니다. 플레이어를 재사용하고 재생/일시정지/취소/종료 이벤트를 연결해 동화의 자동 넘김과 음소거를 보존합니다. 전체 오프라인 캐시에 음원을 포함하고 Safari용 byte-range 응답을 처리합니다.

검증: 693개 실제 디코딩·길이·SHA-256·캐시 확인, 전체 200개 동화 장면의 텍스트 연결, 모바일/태블릿 실제 MP3 진행·pause/resume·취소 경쟁·자동 넘김·음소거·미리듣기, 완전 오프라인 두 장 재생, 206/416 구간 응답, 기존 기기 음성 모드 및 글씨쓰기/게임 회귀 검사. Chrome 69개 렌더링 검사와 실제 화면 증거를 보존합니다.

사람의 실제 청취 평가와 물리 iPad/Android 음질은 미검증입니다. 기계 전사에서 일부 단어가 다르게 인식된 결과도 보존하며 이를 발음/자연스러움 승인으로 표시하지 않습니다. 모든 앱 문장을 변환했다고 주장하지 않습니다. 실제 결과는 `voice-preview.html`에서 들을 수 있습니다. 상세 조건과 재현·한계는 `docs/v13/audio/README.md`에 있습니다.
