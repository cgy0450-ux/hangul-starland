# v13.4.1: 그림 낱말 퀴즈의 기존 기기 음성 전환 수정

새 음성 미리듣기와 동화는 MP3를 사용했지만 그림 낱말 퀴즈는 첫 안내 문장과 이름이 들어가는 칭찬 음원이 없어 기존 TTS로 넘어갔습니다. 실제 퀴즈 문장과 분할 칭찬을 추가 제작하고, 새 음원 모드에서 음성 칭찬은 ‘친구’로 통일합니다. 화면의 이름과 기기 음성 모드의 개인화는 유지합니다. 자동 재생 제한 시에도 기기 음성으로 바꾸지 않고 첫 터치 후 새 음원을 재생합니다.

실제 휴대폰 크기 퀴즈 5문제, 낱말 27개, 칭찬 10종에서 MP3 재생 68회와 기존 기기 음성 호출 0회를 확인했습니다. 태블릿 및 완전 오프라인 낱말/칭찬도 기기 음성 호출 0회입니다. CI에 실제 문장 전체 검사와 autoplay 제한 회귀 검사를 추가했습니다. 746개 실제 MP3 검증, Chrome 69개 렌더링 검사와 기존 음성 상태 검사 통과. 캐시/스크립트 버전을 갱신했습니다.

기존 답 판정·점수·쓰기 기준은 변경하지 않았습니다. 음원 제작은 기존 무료 로컬 모델을 사용했습니다. 실제 기기 청취 품질 승인으로 표시하지 않습니다. 증거는 docs/v13/audio/quiz-regression.json 및 offline.json에 있습니다.
