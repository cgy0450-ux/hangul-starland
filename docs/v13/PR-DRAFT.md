# Show all twenty-four books directly in the story shelf

Adds the four illustrated ten-page books directly to the existing shelf and reader, with the newest four first. No key or separate unlock is required. Preserves the original twenty data entries and all existing book indices; appends four new entries, forty scene images and forty matching recorded clips. Public text and narration use a generic child reference; private original files/key and the legacy encrypted reader remain unchanged.

Recorded playback supports pause, replay and narration-ended auto-next, enabled by default with saved opt-out. Offline worker caches all added text/art/audio. Tests/evidence: docs/v13/unified-stories and qa/v13/additional_stories.py. Browser emulation, not physical-device verification. No paid external API.
