# Replace remaining Korean device voices and improve history illustrations

Reading/history lesson questions, explanations and choices fell back to the device speaker when exact prerecorded text was missing. The release expands to 3311 actual local M4 audio files and makes Korean playback consistently use those clips, including Korean text tagged as English. Old device settings cannot restore system Korean speech. English vocabulary pronunciation retains device English speech. Pause/resume/cancel/autoplay and offline audio remain supported; no paid API.

Shin Saimdang now paints plants and insects in a large purpose-built storybook scene. Eleven other historical figure/object scenes were created and registered, including corrected Hangul in the book scene; applicable questions resolve their actual answer to the scene. Onggi is supporting art for reuse. Sources retained, original mascot and learning/handwriting behavior preserved.

Validation: all 440 unique lesson entries, 1169 recorded starts, zero Korean native calls or missing clips; 57 classic academy/finance routes; four story/parent playback cases; 20 historical scene phone/tablet cases; 72 browser cases; thirteen strict-game regressions; 516-image and 3311-audio decode/hash checks; six negative asset cases; 3933 offline URLs and actual audio/range playback. MP3 temporary files are isolated by worker and all newly synthesized files were regenerated with isolation before final checks.

Physical-device tests, public-site visual inspection and a human naturalness approval for every audio clip are not claimed. Direct Pages access is blocked by this cloud network policy.
