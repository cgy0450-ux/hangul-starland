# v14.10 — 강물 구조 낭독 동화와 매일 캐릭터 1편

## 실제 제공하는 것

‘스파이더맨 — 강물에 빠진 노란 자동차’ 10장. 강가의 길 가장자리가 무너져 차가 얕은 물로 미끄러지고, 스파이더맨이 차를 거미줄로 받치는 동안 구조대가 사람들을 먼저 구조한 뒤 빈 자동차를 꺼내는 새로운 이야기. 첫 독자용 낭독판이며 각 장 제목·본문·기존 M4 목소리의 실제 로컬 음원·마지막 이해 활동을 앱의 공통 책장/리더에 연결한다. 10개 MP3 전체 decode/hash 확인, 총 231.864초(약 3분52초). 유료 API 없음. 개인 이름/열쇠 없음.

**새 장면 삽화는 미완료다.** 내장 도구의 6장면 요청이 출력 심사에서 거절되었다: `0dd57cd2-f806-47d7-859d-07acc9116239`, moderation_blocked/output/other. 세부 사유는 제공되지 않았다. 거절 우회·재시도 없음. 장면과 맞지 않는 기존 그림/이모지/스톡을 대신 넣지 않았다. 새 책은 표지 카드와 본문에 ‘낭독판 · 장면 삽화 준비 중’을 명확하게 표시하며, 빈 이미지 src 요청도 만들지 않는다. 완성된 삽화 동화로 보고하지 않는다.

## 하루 세 편의 선택

기존 20개 전래 이야기 + 호랑이 이야기 = 일반 21편. 스파이더맨 2편, 폴리·마리오·뽀로로·타요 각 1편 = 캐릭터 6편. 캐릭터 1편 + 일반 2편으로 하루 3편만 표시. KST 자정 기준. 같은 날 재방문·새로고침 때 같은 책, 6일에 캐릭터 책이 한 바퀴. 42일 동안 캐릭터는 각7회, 일반 책은 각4회. 새 구조 낭독판은 2026-11-18 KST에 먼저 노출. 이후 차례대로 순환.

기존 책 인덱스/링크·읽기 설정·음성·자동 다음 장 기본값 유지. 새 책 인덱스 26 추가. 학습 과목의 10개 중3개 순환은 바꾸지 않음. 전용 책장도 공통 선택의 해당 인덱스만 제공하며 제한 우회 경로로 확대하지 않음. 전용 암호화 데이터/키는 변경하지 않음.
