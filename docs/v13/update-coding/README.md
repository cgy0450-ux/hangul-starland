# v14.9 — 업데이트 멈춤·오프닝·코딩 조작/그림 수정

## 문제와 변경

- 업데이트는 controllerchange를 최대 120초 기다렸고, 이미 교체된 worker/설치 지연을 충분히 구분하지 못했다. 현재 worker 버전을 다시 확인하여 이미 적용된 경우 바로 새로고침한다. 확인/설치 대기는 제한 시간을 두며 오래 걸려도 조작 가능한 화면으로 복귀한다. 즉시 ‘닫고 기다리기’ 가능. 성공 문구는 worker와 새 페이지 빌드가 모두 목표 버전일 때만 표시한다.
- 서비스워커는 CORE 전체를 매번 동시 다운로드하던 addAll 대신 동시 8개 작업으로 설치한다. 변경 불가능한 해시 파일명 MP3는 이전 캐시의 실제 응답을 복사한다. 새 코드/그림/음원은 내려받고 모든 CORE 저장에 성공해야 활성화한다. 실제 완료 건수 알림. 진도·설정 localStorage 삭제 없음, 부분 설치를 성공으로 처리하지 않음.
- 과목 오프닝 재방문 1초/준비 시간 차감 제거. 그림 준비 완료 후 일반 4.5초, reduced-motion 3초 포스터. 즉시 건너뛰기 유지.
- 4방향 원목/민트 3D 화살표를 내장 도구로 실제 생성, 원본 보존·분할 WebP 기술 내보내기, 방향 직접 검사. 정확한 방향/칸 수를 그림으로 표시하며 이모지나 임의 방향 대체 없음. 생성/해시/출처는 generation.json 및 asset-plan.json.
- ‘보기 선택 → 상자 또 누르기’ 대신 한 번 탭 제출. 실제 Pointer Events 드래그는 선택한 보기의 그림을 움직이고, 놓은 자리 안에서만 제출한다. 바깥/취소는 미제출. 키보드 탭과 native drop도 유지. 놓은 답이 자리에 표시됨.
- 순서 놀이의 무관한 기차 그림을 제거하고 해당 보기의 정확한 그림/낱말/진행 슬롯 표시. 코딩 ‘순서 세우기’는 무관한 낱말 묶음 대신 손 씻기·양치·화분·외출·독서·블록의 실제 3단계 행동 순서. 기존 고품질 원본 소품 재사용. 순서 오류는 진행하지 않음. 다시 듣기는 현재 단계 음성. 정답 후 별 숫자를 즉시 갱신.
- 행동 18개 음원은 기존 무료 로컬 Supertonic M4 설정으로 실제 합성. 전체 3,329 MP3 decode/hash 및 오프라인 연결 검사. 실기기 주관적 청취 승인을 의미하지 않음.

## 검증

qa/v13/update_runtime.py: HTTP 구버전 worker → 실제 새 worker 설치·제어권 교체, 이미 교체된 뒤 적용하기(두 번째 controllerchange 대기 없음), 폰/태블릿 최신 표시, 오프라인 overlay 해제, 멈춘 update 닫기/시간 초과 복귀. 구 캐시 음원 1개 네트워크를 차단해 재사용 확인. 새 행동 녹음의 실제 offline playback.

qa/v13/update_coding.py: 390×844, 1280×800, 360×640에서 한 번 탭·CDP 실제 touch drag·drop 밖 미제출·정확한 방향/칸 수 이미지 decode·잘못된 순서 차단·현재 단계 다시 듣기·최종 다음 버튼. 6개 행동 순서의 각 단계/매칭 이미지/음성 호출 검사. 첫/반복 오프닝이 준비 후 3.2초에도 표시됨. 실제 캡처 직접 확인; 태블릿의 3열 배치와 두 화살표 줄바꿈도 보정.

기존 smoke/72 browser cases와 전체 음원 audit 결과는 V13-STATUS 및 JSON 증거 참조. 초기 smoke가 native drop/출처/캐시 문자열 누락을 검출하여 실제 핸들러·메타데이터·명시 캐시 목록을 보완했다. 검사 기준 완화 없음. 탭 테스트로 기존 즉시 별 갱신 누락도 발견·수정했다.

## 캐릭터 도안 재확인 및 검증 한계

이전 거절 기록은 moderation_blocked/output/other, 요청 35c25070-333e-443a-99c3-49d298799535. 세부 이유는 도구 응답에 없다. 사용자 승인 부재나 이미지 도구 전체 불능이라고 단정할 수 없다. 이번 일반 방향 타일 4개는 생성에 성공했다. 거절된 캐릭터 도안을 표현만 바꾸어 우회/재시도하지 않았다. 주토피아 이전 거절도 유지. 추가 비용 없음. 물리 폰/태블릿·아이 사용성·사람 청취 검수는 실행 환경에서 불가능하므로 미완료로 남긴다.
