# Encrypted family shelf

Four new six-page stories, 24 generated M4 narration clips (528 seconds), eighteen original scene illustrations. Three illustrated books; one text/audio book is visibly marked illustration pending after two image-tool output rejections. No placeholder/stock substitute and no claim that all 24 scenes are illustrated. Existing public story shelf/content retained.

Only authenticated AES-256-GCM ciphertext is published. The random 256-bit decryption key, raw text/audio/art sources and private review screenshots are outside the repository. Secret link fragment stays in the browser, not an HTTP query. Anyone with that link can decrypt; it does not authenticate a named child. Lock clears view, sound and fragment and invalidates an in-flight unlock. Save the link privately; do not publish it in an issue/PR. Public regression evidence contains counts only.

Actual phone/tablet tests cover 48 page renders and recorded starts, 36 image decodes, zero native speech calls, pause/navigation/comprehension, wrong-key rejection and lock/cancel. Offline encrypted decode and real audio pass. Independent artifact audit rejects wrong keys and tampering and checks no key/plaintext passages in public text files. The initial hash/stale-input unlock failure was repaired and the full suite rerun. Physical-device listening and human approval of every clip are not claimed.
